
# Крестики-нолики — игра на JavaScript

Крестики-нолики — браузерная игра для двух игроков, которые по очереди ставят свои символы на игровом поле 3 × 3.

Побеждает игрок, первым заполнивший своими символами горизонталь, вертикаль или диагональ.

Проект выполнен индивидуально в рамках дипломной работы по курсу «Основы программирования» Нетологии.

## Основные возможности

- Игра для двух участников на одном устройстве.
- Игровое поле размером 3 × 3.
- Поочерёдная установка крестиков и ноликов.
- Обновление игрового поля после каждого хода.
- Проверка победы по горизонтали, вертикали и диагонали.
- Отображение сообщения о победителе.
- Возможность начать новую партию.

## Техническая реализация

### Хранение состояния игры

Игровое поле представлено двумерным массивом размером 3 × 3.

Каждый элемент массива содержит символ одного из игроков или пустую строку, если клетка свободна.

Для хранения состояния используются переменные:

```javascript
const players = ["x", "o"];

let activePlayer = 0;
let board = [];
```

`players` содержит символы участников, `activePlayer` определяет текущего игрока, а `board` хранит состояние игрового поля.

### Обработка ходов

Функция `click(row, col)` получает координаты выбранной клетки от предоставленного интерфейса.

После хода соответствующая клетка обновляется, а игровое поле повторно отображается.

Затем выполняется проверка победы.

Если выигрышная комбинация не обнаружена, ход передаётся следующему игроку.

Переключение выполняется с помощью выражения:

```javascript
activePlayer = 1 - activePlayer;
```

### Проверка победы

Функция `checkWinner()` проверяет:

- Все горизонтальные линии.
- Все вертикальные линии.
- Главную диагональ.
- Побочную диагональ.

Для проверки горизонталей и вертикалей используются вложенные циклы.

Если все клетки проверяемой линии содержат символ текущего игрока, функция возвращает `true`.

При обнаружении победителя вызывается предоставленная функция `showWinner()`.

## Установка и запуск

Игра представляет собой статическую веб-страницу и не требует установки зависимостей.

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/potykalov/tic-tac-toe-js.git
cd tic-tac-toe-js
```

**2. Откройте игру**

Откройте файл `index.html` в браузере.

Также игра доступна на GitHub Pages:

[Открыть Крестики-нолики](https://potykalov.github.io/tic-tac-toe-js/)

## Ограничения текущей версии

Игра предназначена для двух участников на одном устройстве.

Компьютерный противник и сетевая игра не предусмотрены.

Отдельная обработка ничьей не реализована: если все клетки заполнены и победитель не определён, сообщение о завершении партии не появляется.
