
# Крестики-нолики — игра на JavaScript

**Крестики-нолики** — браузерная игра для двух игроков, в которой участники по очереди ставят крестики и нолики на поле 3 × 3.

Побеждает игрок, первым заполнивший своими символами горизонталь, вертикаль или диагональ.

Проект выполнен индивидуально в рамках дипломной работы по курсу **«Основы программирования»** Нетологии.

## О проекте

Игра выполнена на основе [дипломного задания Нетологии](https://github.com/netology-code/pb-diplom).

В исходном проекте были предоставлены готовые HTML-разметка, CSS-стили и JavaScript-код интерфейса (`ui.js`). Файл `logic.js` предназначался для самостоятельной реализации игровых правил.

**Моя задача — реализовать логику игры и связать её с предоставленным интерфейсом.**

В ходе работы реализовал создание и хранение игрового поля, обработку ходов, чередование игроков и проверку победы по всем возможным направлениям.

Игровая логика находится в файле [`logic.js`](logic.js). Для отображения поля и сообщения о победителе используются функции, предоставленные в `ui.js`.

## Мой вклад

### 1. Управление игровым полем

- Реализовал создание игрового поля 3 × 3 в виде двумерного массива.
- Добавил хранение текущего состояния клеток.
- Реализовал инициализацию новой партии через функцию `startGame()`.
- Добавил сброс игрового поля и установку первого активного игрока при перезапуске.
- Связал логическую модель поля с предоставленной функцией отрисовки `renderBoard()`.

### 2. Обработка ходов

- Реализовал функцию `click(row, col)` для обработки выбранной клетки.
- Добавил запись символа активного игрока в двумерный массив.
- Реализовал обновление отображаемого поля после хода.
- Добавил проверку победы после установки символа.
- Реализовал передачу хода следующему игроку, если победитель не определён.

### 3. Определение победителя

Реализовал функцию `checkWinner()`, которая проверяет:

- Все горизонтальные линии игрового поля.
- Все вертикальные линии.
- Главную диагональ.
- Побочную диагональ.

При обнаружении выигрышной комбинации вызывается предоставленная функция `showWinner()`, которой передаётся индекс победившего игрока.

## Правила и управление

Игра рассчитана на двух участников, которые играют на одном устройстве.

Первый игрок использует символ `x`, второй — `o`. Первый ход всегда принадлежит игроку с символом `x`.

Игроки по очереди нажимают на свободные клетки игрового поля. После каждого хода проверяется, заполнена ли одним символом горизонталь, вертикаль или диагональ.

Если один из игроков собрал выигрышную комбинацию, на экране появляется сообщение о победителе.

Для начала новой партии предусмотрены кнопки **«С начала»** и **«Играть еще»**.

## Техническая реализация

### Модель игрового поля

Состояние игры хранится в переменных:

```javascript
const players = ["x", "o"];
let activePlayer = 0;
let board = [];
```

`players` содержит символы участников, `activePlayer` — индекс игрока, выполняющего ход, а `board` — текущее состояние поля.

Игровое поле представлено двумерным массивом:

```javascript
[
  ["", "", ""],
  ["", "", ""],
  ["", "", ""]
]
```

Пустая строка обозначает свободную клетку. После хода в соответствующем элементе массива сохраняется `x` или `o`.

### Начало новой партии

Функция `startGame()` создаёт пустое поле, устанавливает первого активного игрока и передаёт состояние поля функции отрисовки:

```javascript
function startGame() {
  board = [
    ["", "", ""],
    ["", "", ""],
    ["", "", ""],
  ];

  activePlayer = 0;

  renderBoard(board);
}
```

Готовый интерфейс вызывает эту функцию при загрузке страницы и при нажатии кнопки перезапуска.

### Обработка хода

Функция `click(row, col)` получает координаты выбранной клетки от интерфейса.

Она записывает символ активного игрока в массив, обновляет отображение поля и проверяет, завершилась ли игра победой.

```javascript
function click(row, col) {
  board[row][col] = players[activePlayer];

  renderBoard(board);

  if (checkWinner()) {
    showWinner(activePlayer);
    return;
  }

  activePlayer = 1 - activePlayer;
}
```

Выражение `1 - activePlayer` переключает текущего игрока между индексами `0` и `1`.

В предоставленном `ui.js` обработчик нажатий передаёт ход в `click()` только при выборе незанятой клетки.

### Проверка победы

Функция `checkWinner()` последовательно проверяет строки, столбцы и две диагонали игрового поля.

Для проверки горизонталей и вертикалей используются вложенные циклы.

Главная диагональ проверяется по элементам `board[i][i]`, а побочная — по элементам `board[i][board.length - 1 - i]`.

Если все клетки одной из проверяемых линий содержат символ активного игрока, функция возвращает `true`. В противном случае — `false`.

### Разделение логики и интерфейса

В проекте используются два JavaScript-файла с разными задачами:

| Файл | Назначение |
| --- | --- |
| [`logic.js`](logic.js) | Реализованная мной игровая логика: состояние поля, обработка хода, переключение игроков и проверка победы |
| [`ui.js`](ui.js) | Предоставленный код интерфейса: обработка нажатий, отрисовка поля, сообщение о победителе и перезапуск игры |

Игровая логика взаимодействует с интерфейсом через функции `renderBoard()` и `showWinner()`.

## Технические задачи и решения

### 1. Хранение и обновление состояния игрового поля

**Задача**

Обеспечить хранение состояния каждой клетки, чтобы после хода игрока можно было обновить отображение поля и проверить результат партии.

**Решение**

Представил игровое поле в виде двумерного массива. Каждому элементу массива соответствует клетка, определяемая номером строки и столбца.

После хода обновляется соответствующий элемент массива, а актуальное состояние передаётся в `renderBoard()`.

**Результат**

Логика игры хранит состояние поля отдельно от его HTML-представления. Интерфейс получает обновлённые данные после каждого хода.

### 2. Проверка всех возможных выигрышных комбинаций

**Задача**

Определять победу независимо от того, в какой строке, столбце или диагонали игрок собрал одинаковые символы.

**Решение**

Реализовал функцию `checkWinner()` с проверкой строк, столбцов и двух диагоналей.

Вместо перечисления отдельных комбинаций для поля 3 × 3 использовал циклы и обращение к элементам двумерного массива по индексам.

**Результат**

Функция определяет победу по любой горизонтали, вертикали или диагонали текущего поля.

### 3. Передача хода между игроками

**Задача**

Обеспечить поочерёдные ходы двух участников и остановить передачу хода после определения победителя.

**Решение**

Использовал переменную `activePlayer` для хранения индекса текущего игрока.

После хода сначала выполняется проверка победы. Если выигрышная комбинация обнаружена, вызывается `showWinner()` и функция обработки хода завершается.

В противном случае индекс активного игрока переключается с помощью выражения `1 - activePlayer`.

**Результат**

Игроки ходят по очереди, а после победного хода отображается сообщение о победителе.

## Ограничения текущей реализации

В текущей версии игра создаёт поле размером **3 × 3**.

Алгоритм проверки победы использует длину массива `board`, однако функция `startGame()` не предусматривает создание поля другого размера.

**Отдельная обработка ничьей не реализована:** если все клетки заполнены и победитель не определён, сообщение о завершении партии не появляется.

Игра предназначена для двух участников на одном устройстве. Компьютерный противник и сетевая игра не предусмотрены.
